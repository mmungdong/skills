# 机构审核风险分类（A/B/C）

| 版本 | v1.0 | 状态 | 2026-09-09 定稿 | 维护 | `review_risk_class` 唯一事实源 |
| --- | --- | --- | --- | --- | --- |

该分类只用于首页标注与审核严谨度参考。agent 对 A/B/C 一律全面审核，不裁剪检查点；最终是否通过由人工复核决定。它不是业务类型轴：不得据此选择、删除、替换或降低任何 `business_types[]` 标签或 business skills。

记录风险等级 `F0000020` 只作先验和一致性对照，不作为分类输入；级次、状态也不参与分类。判定结果写入：

```jsonc
{
  "review_risk_class": {
    "class": "A|B|C",
    "hits": ["A7"],
    "unknown": [],
    "basis": "命中证据摘要",
    "mismatch": false,
    "rigor": "high|standard"
  }
}
```

## 判定输入与顺序

可用信号包括：形态 `F0000056`，对象 `F0000119`，范围 `F0000066`，目的 `F0000064`，业务大类 `F0000065`，监管归属 `F0000082`，证券/司法/金融标志，报告名称 `F0000049` 中真实出现的主体性质词、专用词和可靠金额，以及已读取材料中的定位证据。

1. 先检查 A1–A15；任一自动判定条款命中即为 A，并保留全部 hits。
2. 未命中 A，再检查 B1–B13；命中细分条款时保留全部 hits。
3. 未命中 A/B 时为 C；C1 是兜底，并保留适用的 C2–C7 细分。
4. 同时命中不同档时取最高档，hits 全部保留。
5. B2/B5 所需金额缺乏可靠证据时写 `unknown=待补金额`，不得据此降档。
6. A13/A14/A15 与 B13 含需人工判断的条件，写入 `unknown[]`，禁止臆断升级或降级。
7. 与 `F0000020` 不一致时设 `mismatch=true` 并提示人工确认，不回写或篡改分类。
