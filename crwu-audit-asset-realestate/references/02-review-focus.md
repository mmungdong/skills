# 房地产资产专业审核关注点

以下内容仅归纳现有房地产对象、方法接口与通用披露 RULE 的检查结构。实际判断必须使用 `01-kb-assembly.md` 对应路径键在本次 DWS 快照中的正文，不以本文件替代规则原文。

## 对象边界与权属

- 核对委托范围、报告对象、说明口径、权属资料和资产清单是否指向同一房地产实体或权益范围，特别识别土地、建筑物、构筑物、附着物的纳入与排除；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。
- 核对权属状况、权属证明或承诺、权利限制与已披露瑕疵是否有材料支撑，并在报告相应部分一致呈现；依据 `RULE-01-02-543~578` 与 `RULE-01-02-251~279`，路径键 `REAL_ESTATE_OBJECT`、`REPORT_DISCLOSURE_GENERAL`。

## 实体、权益与区位状况

- 核对评估说明是否覆盖对象的实物状况、权益状况和区位状况，并与现场调查、抽样范围及不可见或隐蔽部分的披露相衔接；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。
- 核对相邻关系、既有权利安排及动产影响等对象状况是否在其确有材料证据时反映到分析中；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。该项不决定租赁等业务标签。

## 用途管制与最优利用

- 核对用途、规划或其他管制条件是否有材料依据，并与评估目的、价值类型和对象现实状态保持一致；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。
- 核对最优利用分析是否以合法使用为前提，并解释其与报告采用假设及结论的关系；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。

## 土地、建筑物、设备界面防重防漏

- 对照报告、说明和资产清单核对土地、建筑物、构筑物、附着物的分项与合并口径，识别边界遗漏或重复计入；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。
- 核对建筑物组成与机器设备、可移动设施之间的归属界面；设备专业判断交对应 asset skill，本技能仅提出房地产边界的一致性 finding；依据 `RULE-01-02-543~578`，路径键 `REAL_ESTATE_OBJECT`。

## 房地产方法适用性接口

- 根据 router 已识别的实际采用或参考方法，核对房地产对象层对市场法、收益法、成本法、假设开发法或基准地价修正法的适用前提、资料条件和方法选择说明；依据 `RULE-01-02-543~578` 与 `RULE-01-02-281~305`，路径键 `REAL_ESTATE_OBJECT`、`VALUATION_METHOD_INTERFACE`。
- 核对单一方法或多方法选择理由及与对象特征的衔接；只输出房地产对象侧适用性接口，不覆盖 method skill 或 business skill 的判断；依据 `RULE-01-02-543~578`、`RULE-01-02-281~305` 与 `RULE-01-02-251~279`，路径键 `REAL_ESTATE_OBJECT`、`VALUATION_METHOD_INTERFACE`、`REPORT_DISCLOSURE_GENERAL`。

## 报告、说明、明细表一致性

- 分别核对报告、评估说明、测算明细表中的对象名称、范围、权属、用途、面积数量、方法和关键假设是否一致；依据 `RULE-01-02-543~578` 与 `RULE-01-02-251~279`，路径键 `REAL_ESTATE_OBJECT`、`REPORT_DISCLOSURE_GENERAL`。
- 将对象侧差异输出为可定位 finding，并按路径键 `EXECUTION_CONTRACT` 的本次快照组织证据与修改建议；每条带 `source_skills[]`。依据 `RULE-01-02-543~578` 与 `RULE-01-02-251~279`，路径键 `REAL_ESTATE_OBJECT`、`REPORT_DISCLOSURE_GENERAL`、`EXECUTION_CONTRACT`。数值公式、合计、跨表勾稽和数据串扰由 public skill 并集处理，本技能不重复下结论。
