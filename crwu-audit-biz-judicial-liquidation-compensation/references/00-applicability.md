# 司法清算与补偿业务适用性

## 一级 canonical label

`司法清算与补偿`（owner_axis = `business`）。一级根 `01-业务路线/07-司法清算与补偿/`；本技能只映射该一级目录，不映射其子业务。

## 业务边界

- 覆盖：司法清算与补偿主线下的评估目的、经济行为与场景规则。
- 不覆盖：对象专业事项（资产轴）、方法正文（method 轴）、监管正文（overlay 轴）、表格勾稽（public 轴）。交叉场景由 router 稳定并集，不新建组合 Skill。
- 报告形态：本技能面向评估报告；咨询/估值文书类目的按其所属主线判定（命中 `08-咨询复核与其他` 时走该一级业务）。

## 子业务识别（`business_subroutes[]`）

识别证据以**报告评估目的原文、经济行为文件、委托合同与相关审批材料**为准；子业务名只作索引键与提示，不得只凭文件名或报告标题判断。同时命中多项全部保留，证据不足时保留合理候选并标记 `review_required=true`。

## 排除与冲突

- 与其他一级业务的边界：以一级目录 `01-业务路线/0N-<一级业务>/` 的归属为准；同一评估目的若同时指向两个一级业务，保留双方并交由 router 并集，不在本技能内合并。
- 本技能不因某个子业务未提供要点文件而扩大或缩小一级路由。

## 多子业务同时命中

全部保留并逐个子业务执行；共用层（`共同审核点`）只执行一次，不因命中集合变化而增删。
