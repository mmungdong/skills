# 房地产（不动产/房产）大方向审核（crwu-audit-realestate）

## ⚠️ 调用前置条件（强制）
本技能是 crwu-audit 审核能力族的**大方向叶子技能**，**禁止被 Agent 直接单独调用**：
必须先由总路由 `crwu-audit` 完成画像（报告形态 → 经济行为角度 → 对象 → 方法 → 监管覆盖层）
并编排本次调用链（含公共检查装载）后，方可执行本技能。
直接单独调用会漏装 M-基准要素一致性 / 披露通用 / 数据勾稽等公共检查，并跳过汇总去重、
适用规则集快照与统计回填 → 审核报告不完整、口径漂移。收到审核请求时：先进 `crwu-audit`。

## 大方向通用审核逻辑（分区）

> 细分技能（如 realestate-rent）会覆盖更细清单；本技能执行"对象层 + 披露通用 + 方法适用"公共逻辑，
> 细分命中时由细分在其清单之外补父级检查。规则只读引用，禁止复制。

### A. 画像与基准要素（承接：报告全分区）
- 报告用途/评估对象（全部或部分权益）/范围/目的 与委托一致且全文统一——不动产准则第九条
  （RULE-01-02-551）；对象边界（土地/建筑物/定着物；不含海域、林木）——第二条（544）。
- 最优利用/用途管制假设：合法前提下结合目的、价值类型——第八条（550）、第七条（549）。

### B. 报告部分
- 权属状况披露（总体情况/主要特点/权属）：第三十五、三十四条（577/576）；权属证明与承诺：
  第六条（548）。**权证到期+续期申请、军产许可等权属瑕疵必须如实披露**（衔接报告准则特别事项）。
- 假设与限制条件披露：第十一条（553）；方法选择及理由/单方法原因披露：评估方法准则
  第二十一至二十四条（RULE-01-02-301~304）+ 不动产第十六条（558）。
- 结论使用有效期/声明等报告要素：按报告准则精编（RULE-01-02-251~279 相应条，读取
  `KB/…/报告准则-精编条目/` 定位）执行。

### C. 评估说明部分
- 实物/权益/区位三大状况描述：第十条（552）；现场调查与抽样/隐蔽披露：第十三条（555）；
  相邻关系/租约/动产影响：第十五条（557）。
- 方法适用与参数按报告所用方法装配：
  - 市场法 → 不动产第十七至十九条（559~561）+ 评估方法准则第四至八条（284~288）；
  - 收益法 → 不动产第二十至二十二条（562~564）+ 评估方法准则第九至十四条（289~294）；
  - 成本法 → 不动产第二十三至二十五条（565~567）+ 评估方法准则第十五至二十条（295~300）；
  - 假设开发法/基准地价修正法 → 不动产第二十六、二十七条（568/569）。

### D. 测算明细表部分
- **表格勾稽必做**：材料含明细/计算/汇总表时，先按 `crwu-audit-datacheck` 跑 C1–C6（合计、跨表口径、公式错误、串扰词、占位残留）再下结论；解析失败须明示"该表未核"；
- 明细与说明/报告勾稽、单位/小数/合计/跨表一致 → M-数据校对口径输出差异清单（不下价值判断）；
- 土地与建筑物分算、设备与不动产界面防重防漏：不动产第十二条（554）。
