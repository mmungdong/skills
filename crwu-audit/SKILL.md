## 2. 分发算法（每次审核按此执行）

1. **画像首判**（可推断则标注"画像来源：推断（置信低）"）：
   `report_type`（评估报告/咨询/估值/其他）→ `object_type` → `method 集合` → `scenario` →
   `stage` → `purpose/base_date`（无基准日留空）。
2. **L1 大方向匹配**：report_type=评估报告 → 按 object_type 命中大方向（realestate 等）。
   report_type=咨询/估值 → 归 advisory/估值大方向（边界引用 RULE-01-02-435：不得以咨询/估值替代法定评估）。
3. **L2 细分匹配**（在大方向内）：按 method/scenario/专项尝试命中细分（如 realestate×出租×租金
   → realestate-rent）。
4. **降级规则**：细分未命中 → 执行其父大方向的通用审核逻辑；大方向未命中 → 用跨对象通用
   评估报告规则动态装配（报告准则/程序/质控）；仍无依据 → **如实返回"该画像暂无对应审核能力/
   无 A 级依据"，禁止硬套其他方向**。
5. **执行**：读取命中技能 `skills/crwu-audit-<…>/SKILL.md`，按其流程完成审核（只读引用
   crwu-knowledge 规则/清单，不复制正文）。
6. **门禁透传**：命中技能所依赖 RULE/清单若为"A 待发布"→ 全程试点模式（意见标
   `[依据待发布]`，先告知用户"正式审核需先 P0 人工发布"）；已发布 → 正式模式。
7. **汇总输出**：意见按 报告/评估说明/测算明细表 分区去重；附**路由路径**（本次 命中→降级 记录）
   与《适用规则集快照》+ 三段式引用 `[kb_id | 出处 | 原文片段]` + 答复/流转字段
   （schema：`KB/audit-skill/06`；防幻觉：`KB/audit-skill/07`，禁止放宽）。
8. **统计回填**：按 `KB/audit-skill/08-审核统计与台账规范.md` 产出单份统计字段（A–G）并落入
   台账（模板 `KB/knowledge-base/05-模板库/审核统计台账-模板.md`）；台账用于周/月/批汇总与
   知识库反哺（易错点候选/缺口反馈）。

## 3. 示例路由

| 材料 | 路由路径 | 执行 |
| --- | --- | --- |
| XX 商铺租金市场价值评估报告（市场法） | report_type=评估报告 → object=不动产(房建/商铺) → L1 `realestate` 命中 → L2 scenario=出租+租金 → `realestate-rent` 命中 | 调用 realestate-rent |
| 某工业厂房抵押市值评估报告（成本法） | L1 realestate 命中 → L2 无对应细分（非租金）→ **降级** | 调用 realestate（大方向通用逻辑） |
| 某企业价值收益法评估报告 | L1 enterprise-value 🅿️ 未实现 → 降级通用评估报告规则动态装配（并提示该大方向技能待建） | 通用兜底 + 提示 |
| 某咨询报告（分成率） | report_type=咨询 → advisory 🅿️ → 参照口径规则装配 + 提示 | 参照口径 + 提示 |

## 4. 边界与纪律

- crwu-audit 是**编排者**：不产出具体审核判断、不替叶子技能下结论；
- 材料缺件/画像歧义 → 先报告缺什么/列出可能画像请用户确认，不猜测；
- 更新路由注册表后：同步 `docs/design-crwu-audit-skills.md` §4 与 `skills/README.md`，
  并按 crwu-ai AGENTS.md 追加 `docs/CHANGELOG.md`。
