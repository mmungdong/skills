# references/00 · KB 逻辑装配表（crwu-audit-external-data）

> 本表 = 库内层级路径寻址键表（路径 = crwu-dws 查询到的知识库内路径；不写知识库名称 / 本地根路径 / 节点 nodeId）。
> 使用：命中本技能 → 本表路径并入本次审核下载清单 → 经 crwu-dws 按路径实时下载正文（下载时刻即最新）→
> 只读引用，出处 = 本次下载文件:行号 + exportedAt。文件零缓存：每次审核重新下载，不做任何正文缓存。
> 分工（单一事实源）：**本技能 = 能力**——数据项抽取、连接器发现与调用、口径标准化、比对留痕；
> **知识库 = 口径**——表 A 触发范围、表 B 数据项触及、表 C 组合映射、表 D 万得条件与降级、结论档位、
> 留痕要求、未检查项、员工补录机制；正文经 crwu-dws 实时下载获得，技能与知识库互不复制正文。
> 索引/校验工具：`crwu-audit-skill-maintainer` 技能的 `scripts/kb_tool.py`（随该技能安装）。
> 路径键写法：逐字使用库内节点名（`by_path` 键 = 原样精确名，不折叠大小写/全半角）；**单文件路径不带 `.md`**；
> 目录路径以 `/` 结尾并递归下载。清单外零下载。
> 知识库文件名 / 结构 / 装配范围变更 → 同步本表路径键并跑 `crwu-audit-skill-maintainer` 技能的
> `scripts/kb_tool.py validate`。

## 不由本表登记的内容

- **方法准则与对象/业务规则**：属 method / asset / business 轴，由 router 按各轴叶子装配；
  本技能只在其被加载时叠加外部数据核验，不复制其他轴的根映射。
- **交付/送达层规范**：`crwu-audit/references/11-html-delivery-spec.md` 为本技能族内正式规范，
  不经知识库下载（《外部数据核验》区定义见该文件）。
- **数据源连接与凭据**：属宿主连接器与部署配置，见本技能 `references/01-connector-access.md`；
  知识库只规定"哪个数据项用哪个源、何时双源"，不规定技术调用方式。

## 失败与出处

下载零命中、多命中、类型不符、跳过或失败时，以 manifest 状态记录对应 gap，不猜测近似路径，
也不凭缓存补正文。最终出处由 manifest 与本次下载物共同形成：本次下载文件、实际行号、库内路径、
运行时 `nodeId` 与 `exportedAt`；运行时值不得写回本文件。
