## 证据优先级与多标签

主要证据是 `F0000065` 业务大类、`F0000064` 评估目的和已真实读取、定位的报告目的原文。字段证据与已核验的报告目的文本优先于 `F0000049` 标题推断。高优先级证据只能否定与其直接冲突的标签，不得压制其他不冲突标签。

对下表每个标签独立检查；每次命中后继续扫描所有剩余标签。同一文本可命中多个一级业务，不得选择单一“主业务”就停止。

## 一级业务标签（`business_types[]` 的取值域）

`business_types[]` 只取**一级业务目录标签**；一个标签对应 `01-业务路线/` 下一个一级目录与一个 `crwu-audit-biz-*` Skill。下表的"命中信号"含历史行为词与目的原文特征——它们是**信号**，不是独立标签，不得再写入 `business_types[]`。

| canonical 一级业务 | 命中信号（历史行为词 / 目的原文特征） |
| --- | --- |
| 资产经营 | 资产租赁、租金、承租、出租；持有增值、资产盘活、运营、自持经营 |
| 交易与处置 | 资产转让、产权转让、资产拍卖、公开拍卖、司法拍卖、资产处置、报废处置、资产收购、购置、资产置换、置入置出、划转 |
| 财务报告 | 财务会计报告目的、财务报告目的、公允价值计量、投资性房地产后续计量、合并对价分摊、资产入账、减值测试、商誉减值测试、资产组减值测试、可收回金额 |
| 融资与债务 | 资产抵押、资产质押、融资担保、接受抵债资产、以物抵债、资产偿债、债务重组、债转股、融资租赁、ABS、发债 |

## 子业务识别（一级业务内部，供叶子二次选用）

子业务不占 registry 行、不建独立 Skill：命中一级业务后，由该 `crwu-audit-biz-*` 叶子在已下载目录包内按原始证据选用下列子业务；父级关系以 `01-业务路线/<一级业务>/<子业务>/` 目录为准。

| 一级业务 | 子业务 |
| --- | --- |
| 资产经营 | 持有价值管理、租赁与租金评估、资产盘活与运营 |
| 交易与处置 | 拍卖与处置、收购与购置、置换与划转、转让与出售 |
| 财务报告 | 公允价值计量、资产入账、资产减值测试 |
| 融资与债务 | ABS及发债、抵债与偿债、抵押与担保、融资租赁 |
| 投资与资本运作 | 增资与出资、并购与重组、股权比例变动、股权转让 |
| 税务与历史确认 | 计税价格、追溯评估 |
| 司法清算与补偿 | 司法委托与涉诉、征收拆迁与补偿、破产清算与解散 |
| 咨询复核与其他 | 价值咨询、其他目的、报告复核 |

子业务识别以报告评估目的原文、经济行为文件、委托合同与审批材料为准，不得只凭文件名或报告标题判断；同时命中多项全部保留，证据不足时保留合理候选并标记 `review_required=true`。

## 命中示例

- `破产清算后拍卖处置` 得到一级业务 `司法清算与补偿 + 交易与处置`（旧词 `破产/清算` 归入前者，`资产处置/拍卖` 归入后者），资产维度另按 03 命中房地产。
- `投资性房地产公允价值后续计量` 得到 `财务报告`；资产维度另命中房地产。
- 字段为“资产租赁”，已核验目的原文又写明“为公开拍卖确定底价”时，保留 `资产经营 + 交易与处置`；不得因租赁字段优先而删除不冲突的另一一级业务。
- `商誉减值测试` 得到 `财务报告`（子业务 `资产减值测试`）；不得为它单列一级业务标签。

每个标签都按 00 记录 `type/source/evidence/confidence/review_required`。字段与文件自述冲突时写入 `conflicts[]`，按 06/08 的 ROUTE 规则处理；不得编造未读取的目的原文。

## 与 07 的关系

04 的每个一级业务标签必须在 07 恰好注册一次；子业务只出现在本表与对应叶子的二级索引中，不进入 07。
