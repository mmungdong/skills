# 不动产-商铺租金/经营性物业市值 评估报告审核（crwu-audit-realestate-rent）

## ⚠️ 调用前置条件（强制）
本技能是 `crwu-audit-realestate` 下的 **L2 细分叶子技能**，**禁止被 Agent 直接单独调用**：
必须先由总路由 `crwu-audit` 完成画像与分发、并在大方向技能 `crwu-audit-realestate` 的
公共检查之上按编排调用本技能。
直接单独调用会漏掉大方向通用项与跨模块汇总 → 审核报告不完整、口径漂移。

> KB 逻辑装配表：本技能 `references/00-KB装配表.md`（审什么的逻辑在知识库，本表=库内层级路径寻址键表，正文经 crwu-dws 实时下载后只读引用；改 KB 内容不动技能）

## 定位与适用画像

> 本技能是 **`crwu-audit-realestate`（房地产大方向）下的 L2 细分能力**：由总路由 `crwu-audit`
> 在"大方向=不动产 + 场景=经营性物业出租 + 租金/市场价值"判据下调用；大方向通用项（A–D：
> 基准要素/权属披露/三大状况/方法适用/防重漏）由本技能在分区清单之外覆盖执行（公共逻辑在父级
> 技能，不在此复制）。

| 画像轴 | 命中范围 |
| --- | --- |
| report_type | **评估报告**（中瑞评报字等正式评估报告）；非评估文书请走参照口径族 |
| object_type | 不动产/房产：商铺、办公、公寓等**经营性物业**（含出租型）的租金或市场价值 |
| method | 市场法（租金/交易比较修正）、成本法（重置与指数修正）、收益法（租约口径，见"部分支撑"说明） |
| scenario | 经营性物业出租 / 一般商业（含军产许可、权证到期续期等特别事项） |
| stage | 报告审核（含一/二/三级意见答复流转） |

> 不适用：企业价值/无形资产/设备/矿业权对象；咨询报告、估值报告；非经营性物业不动产
> （工业/仓储/土地开发等，待 `crwu-audit-realestate-asset`）。

## 主流程（分区执行）

加载清单（单一事实源=经 crwu-dws 实时下载的本次清单文件，禁止在本技能内复制清单正文；行号=本次下载文件内实测锚点行）：

- `06-规则库/清单-M-市场法/不动产-房产-市场法租金比较-报告审核.md`（单文件，CHK-MKT-001~014）
- `06-规则库/清单-M-成本法/不动产-房产-成本法-报告审核.md`（单文件，CHK-CST-001~012）

按**评估目的/场景 × 所用方法**双键取清单——场景为必填装配键（本技能场景=`经营性物业出租`，
受控取值=references/01「KB scenario 装配键」列），并按材料分区逐条执行（清单内已分区）：

| 分区 | M-市场法项 | M-成本法项 |
| --- | --- | --- |
| 报告部分 | CHK-MKT-001~005（方法选择披露/基准要素/租约/权属/假设） | CHK-CST-001~003（单方法披露/适用前提/土地与建筑分算） |
| 评估说明部分 | CHK-MKT-006~012（可比实例/修正链/系数/口径/可靠性） | CHK-CST-004~010（客观成本/复原与更新/指数修正/寿命/贬值） |
| 测算明细表部分 | CHK-MKT-013~014（修正结果与说明勾稽/汇总一致） | CHK-CST-011~012（明细与报告勾稽/房地设备界面防重漏） |

执行纪律：

1. 每条检查点按清单"检查点/典型缺陷"核对并**逐条裁定**；命中缺陷才**输出意见**——未命中的条目也必须留"符合 + 证据"裁定痕（裁定表见下），禁止静默跳过或只挑命中项。
2. 除清单外，方法不确定时经 crwu-dws 实时下载规则原文精编条目（只读引用，勿改）：
   市场法修正依据 `02-资产类型/房地产/对象准则-不动产2017-精编/不动产准则-评估方法.md`
   （单文件，覆盖 558~569）＋评估方法准则三个单文件：
   `03-评估方法/00-评估方法准则2019-精编/评估方法准则2019-精编条目/评估方法准则-总则与市场法.md`、
   `03-评估方法/00-评估方法准则2019-精编/评估方法准则2019-精编条目/评估方法准则-收益法与成本法.md`、
   `03-评估方法/00-评估方法准则2019-精编/评估方法准则2019-精编条目/评估方法准则-方法选择与附则.md`。
3. **收益法/租约内容（部分支撑）**：报告含收益法测算或租约租金口径时，按其材料分区核对
   不动产准则 562~564（收益前提/参数/租约口径披露）与评估方法准则 289~294；说明"该部分
   暂按规则动态核对，M-收益法预装配清单未建"。
4. 通用披露（任意方法都要过）：基准要素一致性、权属状况披露（权证到期/续期、军产许可）、
   假设与限制、结论使用有效期、特别事项序号与完整性——依据报告准则/不动产披露条
   （RULE-01-02-251~279 相应条、RULE-01-02-553/577 等，按《报告准则-精编条目》定位），
   属 M-报告披露/M-基准要素一致性 范畴。
5. 数据勾稽类（数字/单位/合计/跨表一致）交由 M-数据校对 口径输出**差异清单**，不下价值判断。
6. **场景排除回查**：装配清单出现 **scenario 相关排除**（排除原因含“scenario 不命中”）→ 停下
   回路由层核画像（目的/场景是否判错），不得静默继续（OPT-2026-09-07-02）。


## 表格勾稽（必做，先于意见输出）

> 材料含评估明细表/市场法计算表/成本法汇总表等 `.xlsx/.xls` 时，**先跑表格勾稽再出意见**，
> 禁止"只读报告/说明就下结论"。执行契约与工具链（H0 隐藏区禁读 / C1–C6 / openpyxl·soffice /
> 解析失败"该表未核"）**以 `crwu-audit-datacheck` 为唯一执行源，本技能不复制**；要点速记：
> C1 合计/勾稽 · C2 跨表口径一致 · C3 公式错误 · C4 单位/小数 · C5 跨项目模板串扰 · C6 模板/占位残留。
> - 差异清单回传本技能做规则判定（例：Excel 合计与报告结论不符 → 反证报告数字污染，
>   依据 RULE-01-02-561/576/254；修正系数表与说明不一致 → CHK-MKT-013）；
> - 差异条数计入台账 `data_diff_count`（单文件 `00-总纲/执行契约/04-审核统计与台账规范.md`，经 crwu-dws 实时下载后引用）。

## 边界与回退

- 对象/形态/方法组合不匹配 → 不使用本技能，告知可转 `crwu-audit`（总路由）或对应叶子；
- 规则库查不到对应条款 → 空库静默（明示无依据，禁止编造）；
- 文号/条号/日期存疑 → 以官方原文（`06-规则库/素材-官方原文/原文-官方/` 下对应 PDF/提取文本，经 crwu-dws 实时下载）复核后引用；
- 材料解析失败/缺件 → 先报告缺什么，等补齐再审。
