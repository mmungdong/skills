# AuditResult 钉钉回传契约

本契约只负责把步骤 14 已生成并通过最终态校验的内部监控 JSON 回传到固定钉钉团队空间。它不参与审核判断、HTML 渲染或知识库取数。

## 固定目标

| 层级 | 精确名称 | 处理规则 |
| --- | --- | --- |
| 组织 | `中瑞世联资产评估集团有限公司` | `dws profile list` 精确匹配；组织必须唯一，并且有且只有一个 `isOrgCurrent=true` 账号 |
| 企业团队空间 | `00-【系统专用】AI结果回传区（自动同步·请勿删改）` | 只在目标组织下查询 `orgSpace`；必须预先存在且唯一 |
| 结果根目录 | `AI资产评估审核结果` | 只在上述空间根目录逐层精确查找；必须预先存在且唯一 |
| 年份目录 | `YYYY` | 取 `auditTask.auditTime` 的年份；不存在时允许创建，存在时必须唯一且为文件夹 |
| 月份目录 | `MM` | 取同一 `auditTask.auditTime` 的零补齐月份；不存在时允许创建，存在时必须唯一且为文件夹 |

不得创建、重命名或替代组织、企业团队空间、结果根目录；只允许自动创建年份和月份两级目录。不得跨组织搜索、选择相似名称、选择第一项或持久切换 profile。所有远端 ID 必须来自本次 DWS 真实返回，不得写入 Skill source。

## 输入门禁与文件名

输入固定为步骤 14 `render --json-out` 生成的 `审核结果.<项目ID>.json`。上传前再次按渲染后状态校验；校验失败时不得访问钉钉或创建目录。

- 归档年月：`auditTask.auditTime`，必须是带时区的 ISO 8601 时间。
- 重名后缀：`fileTrace.generatedAt`，必须是带时区的 ISO 8601 时间，格式化为 `YYYYMMDD-HHmmssffffff`。
- 远端文件名：`审核结果.<安全化项目ID>.<时间戳>.json`。
- 项目 ID 中不适用于文件名的 `\ / : * ? " < > |` 与控制字符替换为 `_`；不得改写 JSON 内容。

示例：

```text
AI资产评估审核结果/
└── 2026/
    └── 09/
        └── 审核结果.PRJ-2026-0001.20260918-140607123456.json
```

时间戳取 JSON 内既有生成时间而不是上传时钟，使同一最终结果的远端名称可复现。目标月份目录已经存在同名文件时立即停止，禁止覆盖、删除或自动追加随机序号。

## 执行

在本技能目录运行：

```bash
python3 scripts/upload_audit_result.py 审核结果.<项目ID>.json
```

脚本按以下顺序执行：

1. 读取 JSON，并调用本技能交付校验器执行最终态校验。
2. `dws profile list --format json` 精确解析目标组织及其唯一组织默认账号；后续全部命令显式携带返回的稳定 profile，不修改当前 profile。
3. 在该 profile 下列出全部 `orgSpace`，精确解析固定团队空间。
4. 从空间真实 `rootFolderId` 列目录，精确解析固定结果根目录。
5. 在结果根目录下解析 `YYYY`；零命中时创建并读回，多命中或非文件夹时停止。
6. 在年份目录下解析 `MM`；零命中时创建并读回，多命中或非文件夹时停止。
7. 上传前完整列出月份目录；远端文件名已存在时停止。
8. 使用 `dws drive +upload --file-name <远端名>` 上传普通 JSON，写后重新列目录并核对唯一名称、节点 ID；服务端返回文件大小时还必须与本地一致。

任一级列表必须完整分页。零命中、多命中、类型错误、认证/权限错误或写后无法证明成功时均返回非零退出码，不猜测、不重试到其他组织、不把本地审核成功误报为钉钉回传成功。

## 结果与失败语义

成功时标准输出为单个 JSON 对象，至少包含：

```json
{
  "ok": true,
  "corpName": "中瑞世联资产评估集团有限公司",
  "spaceName": "00-【系统专用】AI结果回传区（自动同步·请勿删改）",
  "remotePath": "AI资产评估审核结果/2026/09/审核结果.PRJ-2026-0001.20260918-140607123456.json",
  "nodeId": "来自本次真实上传回执"
}
```

失败时：

- 保留本地 HTML 和 JSON，不回滚已经完成的审核交付。
- 明确标记“钉钉回传失败”，报告失败层级与真实原因。
- 已创建的年份或月份目录属于正式归档结构，不因后续上传失败而删除。
- 不把未经写后读回验证的未知状态宣称为成功；需人工确认远端状态后再决定是否重试。
